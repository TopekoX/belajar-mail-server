    Konsep Linux dan Ubuntu Server¶

    Identitas chapter

    ID: CH-02-01-01 · Kategori/modul: CAT-02 / MOD-02-01 (Command Line dan Administrasi Dasar) · Estimasi: 60 menit · Lingkungan: lab lokal (VM) · Lihat di dashboard

    Catatan verifikasi

    Perintah pada chapter ini dijalankan pada 2026-10-13 di Ubuntu 24.04.3 LTS yang berjalan di WSL2, bukan di VM server. Output di bawah diambil dari uji itu; nilai pada sistem Anda akan berbeda.

    1. Ringkasan¶

    Anda belajar bagian-bagian sistem Linux (kernel, userspace, distribusi), mengapa Ubuntu Server dipilih untuk kurikulum ini, dan perbedaan rilis LTS dengan non-LTS. Ini adalah awal Level 1 dan memperluas persiapan lab dari Level 0.

    2. Tujuan Pembelajaran¶

    1. Menjelaskan peran kernel, userspace, dan distribusi.
    2. Membedakan rilis LTS dan non-LTS.
    3. Memeriksa versi OS dan kernel dari command line.

    3. Prasyarat¶

    • CH-01-01-03 — jalur lab ke produksi; VM lab dari CH-01-01-02 sudah siap.

    4. Materi Teori¶

    4.1 Kernel, userspace, distribusi¶

    Lapisan Peran Contoh
    Kernel Mengelola CPU, memori, perangkat, proses, dan jaringan; menyediakan antarmuka (system call) bagi program Linux
    Userspace Program yang berjalan di atas kernel: shell, utilitas, service bash, ls, systemd, Postfix
    Distribusi Paket terpadu kernel, userspace, pengelola paket, dan kebijakan rilis Ubuntu, Debian

    "Linux" sebenarnya nama kernel. Sistem yang Anda pakai sehari-hari adalah distribusi yang mengemasnya.

    4.2 Mengapa Ubuntu Server¶

    Ubuntu Server adalah distribusi yang umum dipakai untuk server, punya dokumentasi resmi yang luas, dan rilis LTS dengan jadwal pemeliharaan yang jelas. Kurikulum ini memakai Ubuntu Server 24.04 LTS (Noble Numbat).

    4.3 LTS dan non-LTS¶

    • LTS (Long Term Support) dirilis setiap dua tahun (April tahun genap) dan mendapat pembaruan keamanan standar selama lima tahun. Untuk server produksi, pilih LTS.
    • Rilis interim (non-LTS) dirilis tiap enam bulan dengan dukungan jauh lebih singkat. Cocok untuk mencoba fitur baru, kurang cocok untuk server yang harus stabil.
    • Periode dukungan dapat berubah; periksa halaman resmi siklus rilis Ubuntu sebelum memutuskan.

    4.4 Server tanpa GUI¶

    Ubuntu Server tidak menyertakan desktop grafis. Administrasi dilakukan lewat terminal, lokal atau jarak jauh via SSH (CH-02-04-01). Ini mengurangi konsumsi sumber daya dan permukaan serangan.

    5. Praktik dan Implementasi¶

    Checklist persiapan

    • VM lab menyala dan Anda login sebagai pengguna biasa.

    Langkah

    1. Lihat versi distribusi dan kernel (bagian 6).
    2. Catat nama rilis, versi, dan versi kernel di jurnal belajar.
    3. Cari di dokumentasi resmi tanggal akhir dukungan rilis Anda dan catat.

    6. Perintah Linux¶

    # pengguna biasa
cat /etc/os-release
uname -r

    Contoh output (dari uji pada WSL2; kernel di VM Anda akan berbeda):

    PRETTY_NAME="Ubuntu 24.04.3 LTS"
NAME="Ubuntu"
VERSION_ID="24.04"
VERSION="24.04.3 LTS (Noble Numbat)"
6.18.40.1-microsoft-standard-WSL2
    Perintah Fungsi
    cat /etc/os-release Menampilkan identitas distribusi dan versi
    uname -r Menampilkan versi kernel yang berjalan

    7. Konfigurasi¶

    Tidak ada konfigurasi.

    8. Verifikasi¶

    • cat /etc/os-release menampilkan VERSION_ID="24.04".
    • Anda dapat menjelaskan perbedaan kernel dan distribusi tanpa melihat catatan.

    9. Troubleshooting¶

    Gejala Penyebab Tindakan
    Versi bukan 24.04 ISO yang dipakai berbeda Pasang ulang dari ISO 24.04 LTS agar sesuai materi
    Output kernel berbeda dengan contoh Kernel tiap sistem berbeda Wajar; yang penting perintah berjalan

    10. Security Review¶

    • Gunakan rilis LTS yang masih didukung agar mendapat pembaruan keamanan.
    • Jangan menjalankan rilis yang sudah melewati akhir dukungan untuk server yang menyentuh internet.

    11. Latihan¶

    1. Jelaskan dengan kata sendiri apa itu kernel dan apa itu distribusi.
    2. Cari dan catat dukungan rilis 24.04 LTS dari dokumentasi resmi.
    3. Jelaskan situasi ketika rilis non-LTS lebih tepat dan ketika LTS lebih tepat.

    12. Assessment¶

    1. Apa perbedaan kernel dan userspace?
    2. Mengapa produksi memilih LTS?
    3. Perintah apa yang menampilkan versi OS? Versi kernel?

    Kunci singkat. (1) Kernel mengelola perangkat keras dan menyediakan system call; userspace adalah program di atasnya. (2) Dukungan keamanan lebih panjang dan jadwal jelas. (3) cat /etc/os-release; uname -r.

    13. Checklist Kelulusan¶

    • Saya dapat menjelaskan kernel, userspace, dan distribusi.
    • Saya dapat membedakan LTS dan non-LTS.
    • Saya sudah mencatat versi OS lab saya.
