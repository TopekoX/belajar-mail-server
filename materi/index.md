# Materi Mail Server Ubuntu

Dokumentasi pembelajaran membangun dan mengelola mail server dengan Ubuntu Server, dari dasar Linux hingga operasi produksi.

[Kembali ke dashboard kurikulum](../){ .md-button }

## Cara memakai

- Dashboard kurikulum menampilkan peta kategori, modul, bab, prasyarat, dan progres belajar.
- Halaman materi per bab ditambahkan bertahap dan akan muncul di navigasi setelah diterbitkan.

!!! note "Lab bukan produksi"
    Keberhasilan di lab lokal belum berarti siap produksi. Setiap bab membedakan prosedur lab dan produksi.
