# Peta Belajar dan Profil Pembelajar

!!! info "Identitas chapter"
    **ID:** `CH-01-01-01` · **Kategori/modul:** CAT-01 / MOD-01-01 (Orientasi Kurikulum) · **Estimasi:** 60 menit · **Lingkungan:** konseptual · [Lihat di dashboard](../../../#CH-01-01-01)

## 1. Ringkasan

Chapter ini adalah titik awal kurikulum. Anda memetakan kemampuan awal, memahami urutan belajar dari Level 0 sampai Level 15, dan menyusun rencana mingguan yang realistis. Tidak ada instalasi dan tidak ada perintah yang dijalankan.

## 2. Tujuan Pembelajaran

1. Menilai kemampuan awal terhadap kompetensi yang dibutuhkan.
2. Menyusun rencana belajar mingguan yang realistis.
3. Menggunakan dashboard untuk status belajar, checklist, dan ekspor progres.

## 3. Prasyarat

Tidak ada prasyarat chapter. Ini titik awal kurikulum. Anda cukup nyaman memakai komputer dan membaca dokumentasi teknis; pengalaman Linux tidak diwajibkan karena Level 1 membangunnya.

## 4. Materi Teori

### 4.1 Struktur kurikulum

Kurikulum terdiri dari 16 kategori (Level 0 sampai Level 15) yang berisi 136 chapter. Urutannya mengikuti graf prasyarat di dashboard.

| Level | Kategori | Fokus |
|---|---|---|
| L0 | Orientasi dan Persiapan Belajar | Peta belajar, lab VM, etika operasional |
| L1 | Dasar Linux dan Jaringan | Command line, service, DNS, TCP/IP, firewall, SSH |
| L2 | Fundamental Arsitektur Email | MUA, MTA, MDA, SMTP, IMAP, routing MX |
| L3 | Persiapan Ubuntu Server | Menyiapkan server |
| L4 | Domain dan Infrastruktur DNS | Domain dan record DNS |
| L5 | Instalasi Inti Mail Server (Postfix dan Dovecot) | Memasang inti mail server |
| L6 | Mailbox dan Konfigurasi Klien Email | Mailbox dan klien |
| L7 | TLS dan Autentikasi Email | TLS, SPF, DKIM, DMARC |
| L8 | Webmail dan Layanan Pendukung | Webmail |
| L9 | Security Hardening dan Threat Defense | Keamanan |
| L10 | Monitoring, Otomasi, Backup, dan Disaster Recovery | Operasi dan pemulihan |
| L11 | Deployment Publik dan Kesiapan Produksi | Uji publik dan go-live |
| L12 | Operasi dan Administrasi Email | Administrasi harian |
| L13 | Troubleshooting dan Incident Response | Diagnosis dan insiden |
| L14 | Infrastruktur Email Lanjutan (Opsional) | Topik lanjutan |
| L15 | Capstone dan Penilaian Operasional | Penilaian akhir |

### 4.2 Lima tahap lingkungan

Dashboard membagi kurikulum menjadi lima tahap lingkungan. Pindah tahap hanya setelah kriteria tahap sebelumnya terpenuhi.

| Tahap | Cakupan | Lingkungan | Kriteria selesai |
|---|---|---|---|
| 1. Lab lokal (VM) | CAT-01 s.d. CAT-07 | Lab lokal / jaringan privat | Mail flow lokal berfungsi dan relay terbukti tertutup |
| 2. Lab + domain | CAT-08, CAT-09 | Domain milik sendiri | TLS valid, SPF/DKIM/DMARC terbaca |
| 3. Hardening dan operasi dasar | CAT-10, CAT-11 | Lab | Kontrol keamanan terverifikasi, backup teruji restore |
| 4. Uji publik | CAT-12 (modul pertama) | VPS, IP publik, PTR, port 25 terbuka | Konektivitas luar dan FCrDNS valid |
| 5. Produksi | CAT-12 (go-live), CAT-13, CAT-14 | Produksi | Checklist go-live lengkap, runbook, monitoring aktif |

### 4.3 Profil pembelajar dan penilaian diri

Nilai diri Anda dengan skala 0 (belum pernah), 1 (pernah mencoba), 2 (mampu dengan panduan), 3 (mampu mandiri).

| Kompetensi | Skor 0–3 | Dibahas di |
|---|---|---|
| Menggunakan terminal dan menavigasi direktori | | L1 · `CH-02-01-02` |
| Mengelola pengguna, izin, dan paket | | L1 · `CH-02-01-03`, `CH-02-01-04` |
| Mengelola service dengan systemd | | L1 · `CH-02-02-01` |
| Memahami IP, DNS, port, dan firewall | | L1 · `CH-02-03-01` s.d. `CH-02-03-04` |
| Mengakses server lewat SSH | | L1 · `CH-02-04-01` |
| Menjelaskan alur email dan protokolnya | | L2 · `CH-03-01-01` |

Skor 0–1 pada baris mana pun berarti Anda mulai dari L1 secara berurutan. Jika skor 3 hampir di semua baris L1, Anda tetap perlu mengerjakan assessment L1 sebelum melompat ke L2.

### 4.4 Rencana mingguan yang realistis

- Estimasi total jam tiap chapter ada di dashboard. L0 sekitar 4 jam dan L1 sekitar 21 jam 30 menit (lihat halaman level).
- Rencanakan blok 2–3 sesi per minggu, masing-masing 60–90 menit, daripada satu sesi panjang.
- Sisihkan sesi untuk mengulang latihan, bukan hanya membaca.
- Catat kendala di jurnal belajar, tanpa menulis kata sandi atau kunci privat.

**Checklist persiapan**

**Langkah**

4. Tulis rencana mingguan: hari, jam, dan chapter target untuk empat minggu pertama.

## 9. Troubleshooting

| Gejala | Penyebab | Tindakan |
|---|---|---|
| Progres hilang | Data browser dibersihkan atau mode privat | Ekspor JSON secara berkala dan impor kembali |
| Chapter terkunci karena prasyarat | Prasyarat belum berstatus Selesai | Selesaikan chapter prasyarat atau tinjau ulang urutan |
| Rencana tidak terkejar | Target terlalu besar | Kecilkan target mingguan menjadi satu chapter |

## 10. Security Review

- Jangan menyimpan kredensial nyata, kunci privat, atau token di catatan belajar.
- Berkas ekspor progres hanya berisi status dan checklist, tetapi perlakukan tetap sebagai berkas pribadi.
